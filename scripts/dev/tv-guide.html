Catalog on your Fire TV

Watch everything from Mom's Catalog on your own TV. Setting it up takes about 10 minutes, once.

Catalog already on your Fire TV? You don't need to do anything. Keep using it as it is. This is only for a TV that doesn't have it yet.

Before you start

  • Mom's laptop is on, with Catalog open.
  • Your Fire TV is on the same Wi-Fi as the laptop.
  • The laptop's address (on the laptop: Catalog → Settings → Watch on TV):

1. Install Downloader

  1. On the Fire TV's home screen, go to Find (the magnifying glass) and search for Downloader.
  2. Pick the orange Downloader app (by AFTVnews) and press Get or Download. It's free.

2. Let Downloader install apps

  1. Go to Settings (the gear) → My Fire TV → Developer options.
  2. Choose Install unknown apps and turn it ON for Downloader.

No "Developer options"? Go to My Fire TV → About, highlight the TV's name (the first line) and press OK seven times. A message says you're a developer, and Developer options appears.

3. Install Catalog

  1. Open Downloader. If it asks for permission to use files, choose Allow.
  2. In the address box, type this code and press Go: {{CODE}}
  3. In the address box, type the laptop's address followed by /catalog-tv.apk, like this:
    http:// /catalog-tv.apk
  4. When it finishes downloading, press Install, then Done.
  5. Downloader offers to delete the file it downloaded: choose Delete (twice). You don't need it any more.

4. Open it and pick who's watching

  1. Open Catalog from Apps on the home screen. To keep it on the home row, highlight it, press ☰ (menu) and choose Move.
  2. It finds Mom's laptop by itself. If it asks, type the laptop's address (Catalog → Settings → Watch on TV on the laptop).
  3. If it asks for a PIN, type Catalog's PIN with the number keys on screen.
  4. On Who's watching?, pick your name. Not there yet? Choose Add profile, type your name and choose Save.

Your profile has your own Continue Watching, the episodes you've watched, and My List. Nobody else's gets mixed in.

If something isn't working

Can't find the computerMom's laptop may be asleep, closed, or Catalog isn't open. Wake it, open Catalog, then open Catalog on the TV again. On the laptop, Catalog → Settings → Watch on TV says if Windows set the Wi-Fi to Public (TVs can't connect then), with a button to fix it.
A video won't startPress ↩ and try once more. Another episode or film usually plays fine.
Catalog on the TV looks oldIt updates by itself from Mom's laptop. Only reinstalling the app itself (step 3) ever needs doing again, and only if Mom asks.

For Mom's laptop

  • Keep it plugged in and open (a closed lid makes it sleep), with Catalog open.
  • Stop it going to sleep: Start → Settings → System → Power & battery → Screen, sleep & hibernate timeouts, and set "When plugged in, put my device to sleep after" to Never. The screen turning off is fine.
  • Several TVs (Fire TV and Roku) can watch at the same time.

Catalog on your Roku

Watch everything from Mom's Catalog on your Roku TV. Setting it up takes about 5 minutes, once, with the Roku remote in your hand and Mom's laptop next to you.

Before you start

  • Mom's laptop is on, with Catalog open.
  • Your Roku is on the same Wi-Fi as the laptop.
  • On the laptop, Catalog → Settings → Watch on TV has a Catalog on a Roku section. If it doesn't, update Catalog first (Settings → Updates).

1. Turn on the Roku's developer mode

  1. On the Roku remote, at the home screen, press: Home Home Home ▲ ▲ ▶ ◀ ▶ ◀ ▶
  2. A Developer Settings screen opens. Choose Enable installer and restart, then agree to the license.
  3. Pick a password and write it here:
  4. The Roku restarts. That's all on the Roku.

Roku only lets apps from outside its store in this way. It's safe, and it stays on.

2. Install Catalog from Mom's laptop

  1. On the laptop, open Catalog → Settings → Watch on TV, and find Catalog on a Roku.
  2. Click Find Rokus. Your Roku shows up with its name and Developer mode on. Click it.
  3. Type the password from step 1 and click Install on (your Roku's name).
  4. It says Installed, and Catalog opens on the TV by itself. It stays in the Roku's list of channels.

Roku not in the list? On the Roku: Settings → Network → About shows its IP address. Type it in the box under the list and click Add.

3. Open it and pick who's watching

  1. Open Catalog from the Roku's home screen.
  2. It finds Mom's laptop by itself. If it asks, type the laptop's address (shown on the same Watch on TV page).
  3. If it asks for a PIN, type Catalog's PIN.
  4. On Who's watching?, pick your name.

A new version of the Roku app goes on the same way: step 2 again, over the old one. Nothing you saved is lost.
